A small two-line robot confession: the robot apologizes for sending the grocery list to the boss instead of its partner, then states the lesson it learned — read the recipient's name twice before pressing send.

## Run it

```bash
python3 main.py
```

This writes the two-line apology to `/output/entry.txt`. The output is byte-identical on every run: deterministic, offline, and stdlib-only.
